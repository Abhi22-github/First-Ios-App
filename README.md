# 📱 First iOS App — SwiftUI

A simple and clean **SwiftUI** based iOS application demonstrating basic UI, state management, and navigation.  
Suitable for beginners and Android/Kotlin developers transitioning to iOS.


## 🌟 Features

- SwiftUI-based UI  
- State management using `@State`  
- Navigation using `NavigationStack`  
- Counter example  
- Details screen  
- Clean and beginner-friendly code  


## 🛠️ Tech Stack

- Swift 5  
- SwiftUI  
- Xcode 15+  
- iOS 17+  


## 🚀 Getting Started

### 1️⃣ Clone the repository
```bash
git clone https://github.com/Abhi22-github/First-Ios-App.git
```

### 2️⃣ Open the project
```bash
cd FirstIosApp
open FirstIosApp.xcodeproj
```

### 3️⃣ Run the app
Press ⌘ + R in Xcode to run on the simulator or device.
